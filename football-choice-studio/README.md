# Football Choice recreation

A 720×1280, 21.88-second game-style recreation of `VID-20260926-WA0001.mp4`.

## Production assets

- `messi.png`, `ronaldo.png`, `angel.png`, and `devil.png` are original generated RGBA character assets.
- Each character was generated against a uniform chroma background, keyed, trimmed, and verified to have a fully transparent corner pixel. No baked checkerboard, white, or black background is used.
- `game-road.png` is the fixed perspective game board.
- `lips.png` and `glove.png` are transparent choice-object overlays.

## Timeline

The render uses a fixed game-board camera, animated character bounce, falling lips/glove choices, timed angel and devil entrances, engagement text from 17.2 seconds, and a follow CTA from 19.3 seconds. The supplied reference soundtrack remains synchronized through the 21.88-second ending.
