# Route: reference-video-recreation

- **Input:** One or more reference videos plus a request to recreate, match, reproduce, or implement their editing/animation style. Replacement copy, branding, or media may also be supplied.
- **Output:** A quantified timestamped style specification, persistent full-resolution asset package, editable HyperFrames composition, comparison evidence, review server, and final MP4.
- **Triggers:** “recreate this video,” “match this exact editing style,” “analyze this channel frame by frame,” “copy the movement/timing/color grading,” or “make another video like this reference.”
- **Not this route:** adding captions without changing footage (`embedded-captions`), adding information cards over untouched talking-head footage (`talking-head-recut`), or merely cutting/reframing footage without a style-matching brief (`general-video`).

## Interview

- **Must have:** identify the reference file(s). If multiple exist, establish which upload/date is the target when styles differ.
- **Ask only when missing:** whether content should be duplicated or replaced; required replacement copy/assets; output destination/aspect when not implied by the reference; ownership/permission confirmation.
- **Do not ask:** whether quality may be reduced to save time. Quality is fixed as the priority; optimize only repeated computation and infrastructure.
- **Deferred asks:** exact output codec/resolution can wait until analysis reveals source properties unless the user already specified them.
- **Pitch round:** skip when the user requests an exact match. For “inspired by” requests, pitch controlled variations only after the measured base style is documented.
- **Run-shape:** automation by default; companion mode is allowed when the user wants to approve the style spec, assets, or scene comparisons interactively.
