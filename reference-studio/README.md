# Reference Recreation Studio

This Hyperframes project is the workspace for reference-led video recreation.

## Upload references

Open the Studio, then click the **upload arrow** in the Files panel. You can also drag files onto the `references` folder. Video uploads are limited to 500 MB per file.

Put source/reference material in `references/` and production assets in `assets/`.

## Useful prompt details

Along with each reference, specify:

- target aspect ratio and duration
- which text, colors, logo, footage, and audio to replace
- whether pacing, transitions, typography, camera movement, or all of them should match
- desired output filename and resolution

Only upload material you have permission to use. The recreation can match production characteristics closely while using your own content and branding.
